# nixos-config

My NixOS setup for a **ThinkPad X1 Yoga Gen 3** (i7-8650U, UHD 620): Hyprland with the Noctalia shell, a CachyOS BORE kernel, and hardware fixes for the touchscreen, pen and 360° hinge.

## Layout

```
nixos-config/
├── flake.nix                  inputs and the one system: nixosConfigurations.X1
├── flake.lock
├── hardware-configuration.nix generated by nixos-generate-config
├── LICENSE                    MIT
├── MANUAL-SETUP.md            what a rebuild doesn't bring back: logins, keys, accounts, FAU setup
├── home/                      my personal settings (Hyprland, Noctalia, kitty, fish, VS Code); adopt.sh adds them
├── hosts/
│   ├── X1.nix                 the machine: boot, desktop, users, packages, services
│   └── noctalia.nix           Noctalia shell: package, binary caches, auto-restarting user service
├── modules/
│   ├── home.nix               home-manager: links ~/.config to home/, editable and tracked by git
│   ├── health.nix             Google's ghealth tool and a twice-daily sync of my Fitbit data to ~/.local/share/health
│   ├── health-sync.py         the sync itself: one JSON file per data type and day
│   ├── performance.nix        VA-API video, zram, battery charge limit 85–90 %, AC-aware power profiles, 1 s boot menu
│   ├── tablet-mode.nix        keeps the Wacom touchscreen and pen alive after suspend; turns off keyboard,
│   │                          touchpad and TrackPoint in tent and tablet mode
│   ├── agent-bridge.nix       a fixed set of root actions AI agents may start (see below)
│   ├── battery-guard.nix      pop-ups at 20, 10 and 5 % battery; clean shutdown at 4 % instead of running flat
│   └── fau-remote.nix         `fau` / `ssh fau`: connects eduVPN if needed, then the Compute Cloud VM;
│                              `ssh cip` / `ssh gpu` for the CS CIP pool
└── vm/fau/                    the Ubuntu VM at FAU (not NixOS): setup.sh, the AGENTS.md rules every
                               agent there reads, and vmcheck (lists work not yet pushed to GitHub)
```

## Inputs

| Input | Used for |
| --- | --- |
| `nixpkgs` (unstable) | everything by default |
| `nixpkgs-prev` | a pinned older nixpkgs for Noctalia, Codex and Pixi |
| `noctalia` | the desktop shell |
| `nix-cachyos-kernel` | the CachyOS BORE kernel |
| `nixcare` | my [NixOS care tool](https://github.com/mteyra/nixcare): store cleanup and update checks |
| `antigravity-nix` | Google Antigravity |
| `home-manager` | links my personal settings in `home/` into `~/.config` |

## Use

```sh
sudo nixos-rebuild switch --flake /etc/nixos#X1
nix flake update            # update all inputs, then rebuild
```

`hardware-configuration.nix` belongs to this one laptop. On a different machine, generate a new one with `nixos-generate-config`.

Logins, keys, personal settings and the FAU setup aren't part of a rebuild. [MANUAL-SETUP.md](MANUAL-SETUP.md) lists them, with how to set each one up on a new computer.

## Agent bridge

AI agents run in sandboxes where `sudo` can't work. `modules/agent-bridge.nix` exposes three fixed systemd units instead: rebuild-and-switch, rebuild-for-next-boot (never reboots), and a root-only diagnostics snapshot. Logs go to `/var/lib/agent-bridge/`. With `services.nixcare.agentBridge.mode = "auth"` (set in `hosts/X1.nix`), starting them asks for the password once per session. `"open"` would make them passwordless, which is effectively root for any process running as my user. To remove the bridge, delete it from `hosts/X1.nix` and rebuild.
